# B.E Solutions & Technology website

Static, responsive website source files.

## Preview
Open `index.html` in a browser. The site loads Google Fonts and photography from Unsplash, so those visuals need an internet connection.

## Main files
- `index.html` — page content and SEO metadata
- `styles.css` — layout, visual design, and responsive styles
- `script.js` — navigation, project filters/details, and enquiry form behavior
- `favicon.svg` — site icon
- `robots.txt` and `sitemap.xml` — search crawler files
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow

Edit the `projects` list near the top of `script.js` to update project cards. The enquiry form validates the fields and opens WhatsApp with the enquiry prefilled; it does not store form submissions on a server.
